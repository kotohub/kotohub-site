# kotohub-site

kotohub のアプリ紹介・プライバシーポリシー・サポートページ（GitHub Pages）。

| URL | ファイル |
|---|---|
| https://kotohub.dev/ | `index.html` |
| https://kotohub.dev/tokei-master/ | `tokei-master/index.html` |
| https://kotohub.dev/tokei-master/privacy/ | `tokei-master/privacy/index.html` |
| https://kotohub.dev/tokei-master/support/ | `tokei-master/support/index.html` |

- 共通の見た目は `assets/site.css`。
- アプリを増やすときは `<app-slug>/{index,privacy/index,support/index}.html` を同じ形で追加し、トップの一覧にも足す。
- プライバシーポリシーを変えたら「最終改定日」を更新する。ストアの申告（App Store のプライバシー情報・Google Play のデータ セーフティ）と内容をそろえること。
